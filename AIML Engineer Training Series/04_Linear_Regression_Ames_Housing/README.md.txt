# Ames Housing Price Prediction

## Overview

This project predicts residential house prices using the **Ames Housing dataset** and demonstrates a complete machine learning workflow from data preprocessing to model evaluation and Kaggle-style prediction generation.

## Problem Statement

Given various numerical and categorical features describing residential properties, predict the final sale price of a house.

## Dataset

* **Source:** Ames Housing Dataset
* **Target Variable:** `SalePrice`

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Machine Learning Workflow

* Data loading and exploration
* Missing value analysis
* Numerical and categorical preprocessing
* ColumnTransformer pipelines
* Linear Regression
* Ridge Regression
* Cross-validation
* Model evaluation (R², MAE, RMSE)
* Kaggle-compatible submission generation
